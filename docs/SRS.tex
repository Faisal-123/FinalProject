\section{Introduction}
EagleNav is a navigation app using AR for campus directions.

\section{Functional Requirements}
\begin{itemize}
\item User selects destination
\item App displays AR directions
\item App provides voice instructions
\end{itemize}

\section{Non-Functional Requirements}
\begin{itemize}
\item Easy to use
\item Fast response time
\item Works on mobile devices
\end{itemize}
