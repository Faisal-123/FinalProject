\section{Introduction}
\subsection{Purpose}
This document explains the software requirements for the mobile application, EagleNav.

\subsection{Intended Audience}
Developers and stakeholders.

\subsection{Overview}
EagleNav helps users navigate campus using AR.

\newpage
\section{Interface Requirements}
\subsection{User Interface}
\begin{enumerate}
\item{The mobile application shall provide AR navigation on campus.}
\item{The mobile application shall provide voice guidance.}
\item{The mobile application shall provide users with settings to help customize the features provided by EagleNav locally.}
\end{enumerate}

\subsection{Hardware Requirements}
\subsubsection{Frontend}
Users will need a mobile device with GPS capabilities and internet access (whether celluar or otherwise). For AR capabilities, the mobile device will need to have a camera. For voice guidance, the mobile device will need to have microphones and speakers.

\subsubsection{Backend}
A server (or servers) able to run Docker and the ability to handle network connections.

\subsection{Software Requirements}
\subsubsection{Frontend}
The following lists out the minimum required interfaces so that the app can run. Note that this leads to a usable, though limited, experience for EagleNav users.
\begin{itemize}
\item{Internet Access}
\item{GPS}
\item{React Native}
\end{itemize}

The following lists out the recommended interfaces in addition to the required interfaces. Devices meeting these requirements helps lead to an ideal experience.
\begin{itemize}
\item{Microphone}
\item{Speaker}
\item{Camera}
\item{ARCore / ARKit}
\end{itemize}

\subsubsection{Backend}
\begin{itemize}
\item{Network connection}
\item{Docker (Note that the Docker images must be able to run/support the following):}
\begin{itemize}
	\item{Express.js}
	\item{MongoDB}
	\item{Node.js}
\end{itemize}
\end{itemize}

\subsection{Communication}
Users will be able to contact the EagleNav team via email to report bugs, issues, or to submit general feedback. This communication will be handled in compliance with relevant data protection laws and regulations, including the ones set out in the CCPA.

\newpage
\section{Legal and Ethical Considerations}
User data must be handled securely and respectfully. To that end, camera data is used solely for AR navigation purposes, and GPS data is only used to ensure proper navigation directions. Such data is never stored once processed. In addition, dictation data for voice navigation is processed on-device and never stored.
