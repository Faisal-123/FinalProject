\section{Introduction}
\subsection{Purpose}
This document describes the design of the EagleNav system.
EagleNav is an augmented reality navigation platform. EagleNav aims to remove navigation barriers and create a more inclusive campus experience for all students 


\subsection{Intended Audience}
This document is intended for students, developers, and instructors.

\subsection{Overview}
EagleNav provides indoor/outdoor campus navigation with accessibility-aware
routing, campus events, and safety shortcuts. 

\newpage
\section{System Architecture}
The system includes a mobile frontend, backend server, and database.

\subsection{Dependencies}
The following dependencies are utilized:

\subsubsection{Frontend}
\begin{itemize}
\item{ARCore / ARKit}
\item{React Native}
\end{itemize}

\subsubsection{Backend}
\begin{itemize}
\item{Docker}
\item{Express.js}
\item{MongoDB}
\item{Node.js}
\end{itemize}


\subsection{Workflow}
Users will start on the homepage when the app launches. Then, users can either configure settings, or go to the main navigation page.

\vspace{3pt}
\hspace{-14pt}From the main navigation page, the primary workflow is described as follows:

\begin{enumerate}
\item{User selects a destination}
\item{App processes the request}
\item{The backend retrieves the request and returns directions}
\item{The app receives the response and displays the directions to the user}
\item{The user navigates towards the destination, with AR features helping to guide users throughout a navigation session}
\end{enumerate}


\subsection{Architecture Breakdown}
EagleNav's architecture is organized into three tiers: cloud infrastructure, on-device controllers, and on-device services. Cloud infrastructure provides helps host the backend services for EagleNav, while the on-device controllers help to delegate communication between the backend and the frontend. On-device services helps assist in user navigation via AR support and GPS location data.

\section{User Interface}
Users interact through a mobile app with AR directions and voice guidance. The following list represents the primary pages that users will interact with:

\begin{itemize}
\item{\textbf{Home Screen:} Users will be able to access the navigation screen, settings, and get basic information at a glance.}
\item{\textbf{Navigation Screen:} Users will be able to navigate the campus using AR + Map Navigation features.}
\item{\textbf{Settings:} Users will be able to locally change the app's theme, navigation volume, AR settings, etc.}
\end{itemize}
