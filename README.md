# EagleNav
> *Please note: This repository does not serve as the actual repository for EagleNav. Rather, this is a mock repository for the final project as part of CS 3338-02 Spring '26*

## Project Overview
EagleNav is a mobile app that helps users navigate the Cal State LA campus using augmented reality (AR). It shows directions with visual arrows and provides voice guidance.

## Purpose
The goal of this project is to make campus navigation easier, especially for students with disabilities. It helps users move around campus safely and independently.

## Features
- AR navigation with on-screen arrows  
- Voice directions  
- Obstacle awareness  
- Campus map and location info  

## Technologies Used
- Mobile development (Android / iOS)  
- Augmented Reality (AR tools)  
- Sensors (camera / LiDAR)  
- Mapping and navigation algorithms  

## Installation
1. Clone the repository  
2. Open the project in your IDE  
3. Install dependencies  
4. Run the app  

## Usage
1. Open the app  
2. Choose a destination  
3. Follow the AR directions  
4. Listen to voice instructions if needed
